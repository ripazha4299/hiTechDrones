Software Cost Per Drone

—
    Assumptions & methodology

    Development & integration (amortized)

    Military: ₹1 crore baseline build/certify cost for the analytics stack (model dev, DGAQA-style accreditation, EW-hardened integration), amortized across fleet size over a 4-year refresh cycle.

    Agri: ₹15 lakh baseline commercial CV build (production-grade), amortized over fleet size over a 3-year refresh cycle — consumer hardware/software turns over faster.

    Compute, bandwidth & storage

    Scale with sensor tier (more channels → more inference and data volume) and processing location. Edge processing raises one-time hardware amortization but cuts bandwidth, since only flagged events — not raw video — get uplinked. Military storage carries a security premium for encrypted/air-gapped archives.

    Human review & maintenance

    Review cost = coverage % × base analyst-hours/drone/year × hourly rate (₹400/hr cleared analyst, military · ₹150/hr commercial annotator, agri). Maintenance scales with retraining/update cadence.

    Compliance overhead

    Flat per-drone allowance: DGAQA/CEMILAC-equivalent certification upkeep for military; basic data-privacy compliance for agri.
